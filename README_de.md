### Fall 1: [Monsterverfolgung auf einer Hängebrücke im Sturm](https://x.com/mi7_crypto/status/2120862780312191148) (von [@mi7_crypto](https://x.com/mi7_crypto))

| Ausgabe |
| :---: |
| <a href="https://video.twimg.com/amplify_video/2120862695088087040/vid/avc1/1920x1080/uiETd7WaE9PWQrL5.mp4?tag=29"><img src="https://pbs.twimg.com/amplify_video_thumb/2120862695088087040/img/MF-zh-DFV44QW1MQ.jpg" width="300" alt="Monsterverfolgung auf einer Hängebrücke im Sturm"></a> |

**Prompt:**

```
[設定・全体要件]
主人公の女性のみ「@ Image黒髪ショートボブの日本人女性、黒タクティカルジャケット）」を完全に参照。その他の要素（スポーツクーペ、巨大怪獣、崩壊する吊り橋）は以下テキスト描写から新規生成。実写シネマティック、縦型16:9画角、ハリウッド級ディザスターアクション。夜、激しい豪雨と雷鳴。カメラは車両追従、車内接写、巨大怪獣を見上げるローアングルをシームレスに繋ぐ30秒連続動画。

[00:00 - 00:04] 衝撃の開幕（ローアングル）
激しい豪雨が叩きつける夜の巨大な海上吊り橋。路面スレスレの極端なローアングルから、画面を覆うほど巨大な「多肢・甲殻に覆われた四足歩行の異形の巨大怪獣（ゴジラではない、複数のトゲと頑丈な腕を持つ生物）」の巨大な脚が、アスファルトや街灯を粉砕して踏み下ろされる。そこへ、マットブラックのカスタムスポーツクーペ（ワイドボディ、一文字の赤色LEDテールランプ）が、激しい水しぶきを上げながら画面手前から奥へと猛スピードでドリフトしながら突入する。

[00:04 - 00:10] 車内の緊迫（タイトショット）
カメラが車内の「Image 1」の女性ドライバーの顔・上半身にクローズアップ。彼女は冷静で鋭い眼光で前方に集中し、激しくステアリングを切り、シフトレバーを操作する。彼女の肌や黒のレザージャケット、窓ガラスは激しい雨で濡れており、外では切断された吊り橋の太いワイヤーが火花を散らして暴れている。

[00:10 - 00:17] 怪獣の咆哮とチャージ（後方追従）
カメラは車外の後方へスムーズに移動し、疾走するスポーツカーと、行く手を阻むようにそびえ立つ、ゴジラとは全く異なる形状の、トゲと甲殻に覆われた多肢の超巨大怪獣を同一フレームに捉える。雷光の中、怪獣が異形の咆哮を上げ、胸部から喉元、口内にかけて「赤橙色の生物発光・高熱プラズマエネルギー」が激しく充填・発光する。車は崩落する路面や落下する瓦礫を避けて、激しくジグザグにフル加速する。

[00:17 - 00:24] 断裂する橋・大ジャンプ（側面〜スローモーション）
並走するカメラワーク。前方の橋桁が完全に崩壊し、奈落の海が露出している。スポーツカーがリアから青い火力を噴射するような勢いで、断裂部から大空へ決死の大ジャンプ！直後、背後の橋桁を怪獣の赤橙色の高熱プラズマ流がなぎ払い、巨大な爆炎と火の粉、衝撃波が車の真後ろで大炸裂する。ジャンプ中の車と、大爆発する背景を、下から見上げるスローモーション（スピードランプ）で捉える。

[00:24 - 00:30] 決死の着地と余韻（正面クローズ）
対岸の崩れかけた路面へ、車が激しい火花とサスペンションのきしみを上げて着地。スポーツカーは180度スピン（Jターン）しながら滑り込み、急停車する。カメラはフロントガラス越しの女性ドライバー「Image 1」の冷徹で息を切らした表情と、その背後で大炎上・崩落する巨大吊り橋、そして闇夜と雷鳴の奥にそびえ立つ、赤くくすぶる異形の巨獣のシルエットを捉え、映画のタイトルのようにフェードアウト。
```

> [!NOTE]
> Der Originalbeitrag enthält kein Referenzbild für die Figur. Im Prompt stehen sowohl Hochformat als auch 16:9. Lege bei der Anpassung ein Seitenverhältnis fest.
