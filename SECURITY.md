# Security Policy

This repository contains documentation, prompt text, and media references; it does not ship production application code.

Report security-sensitive issues privately to `support@evolink.ai` and include the repository name, the affected public URL, and reproduction details. Do not open a public issue for leaked credentials, malicious links, compromised media, or vulnerabilities affecting linked services.

For ordinary broken links, attribution corrections, or prompt content issues, use the public issue templates.
